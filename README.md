# Hangman Game Using Python

## Project Description
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Internship.

In this game, the computer randomly selects a word from a predefined list, and the player has to guess the hidden word by entering letters.

The player gets a maximum of 6 incorrect guesses.

## Features
- Random word selection.
- Five predefined words.
- Six incorrect guessing attempts.
- Displays correctly guessed letters.
- Checks correct and wrong guesses.
- Displays win or game over messages.

## Technologies Used
- Python

## Key Concepts Used
- Random Module
- While Loop
- If-Else Statements
- Strings
- Lists

## How to Run
1. Download the `hangman.py` file.
2. Open the file using Python.
3. Run the program.
4. Enter one letter at a time to guess the hidden word.
5. Continue guessing until you win or use all six incorrect attempts.

## Sample Output

```text

Guess the hidden word.

Word: _ _ _ _ _ _
Guess a letter: p
Correct guess!
```
